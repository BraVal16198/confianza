ConfianzaMicro — Microfinanzas para asesores

ConfianzaMicro es una demostración de portafolio de una aplicación Flutter orientada a asesores de microfinanzas. Permite explorar un flujo realista de trabajo diario: autenticación con credenciales de prueba, menú operativo, consulta de clientes, seguimiento de tareas y vista de portafolio. Todo el contenido usa datos simulados; no se otorgan créditos, no hay cobros reales y no se conecta a un core bancario.

La demo corre en el navegador. No hace falta clonar el repositorio ni crear una cuenta de GitHub para usarla. GitHub Pages solo actúa como hosting estático HTTPS. El enlace al código fuente es opcional para quien quiera revisar la arquitectura.

Qué incluye esta demo

Pantalla de bienvenida animada, inicio de sesión con validación de formulario, persistencia de sesión en el navegador, menú del asesor con accesos a portafolio, clientes, tareas, cobranza, solicitudes, reportes, visitas y configuración. Las secciones de clientes y tareas operan sobre un almacén en memoria con registros de ejemplo (scores, saldos, fechas de visita y estados de tarea). Las rutas restantes muestran stubs claros de funcionalidad en desarrollo.

Cómo probar

Credenciales demo: código A001 con contraseña 1234 (Asesor Confianza) o código A002 con contraseña 5678 (María González). Tras ingresar verás el menú principal y podrás navegar entre módulos sin instalar Flutter. Esta pieza está pensada para revisión de talento frontend/móvil: Clean Architecture (UI, Core, Domain), GoRouter, Material 3 y servicios mock listos para sustituir por API real.

Alcance y límites

ConfianzaMicro no es un producto financiero en producción. No almacena datos personales sensibles en servidores, no cumple requisitos SBS/PCI y no debe usarse para operaciones reales. El objetivo es demostrar calidad de interfaz, estructura de código, despliegue web con SEO técnico (title, meta, Open Graph, Twitter Card, canonical, robots, sitemap, llms.txt, contenido crawler-visible en español) y buenas prácticas básicas de seguridad y accesibilidad en un SPA Flutter servido por HTTPS.
