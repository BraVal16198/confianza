ConfianzaMicro es una demostración de portafolio de software publicada en https://braval16198.github.io/confianza/ por el autor de GitHub BraVal16198.

El sitio muestra una aplicación Flutter de ejemplo orientada a asesores de microfinanzas. Todo el contenido y las credenciales son simulados. No constituye oferta de servicios financieros, intermediación crediticia ni asesoría regulada.

El código fuente está disponible en github.com/BraVal16198/confianza. Uso permitido: educativo y de revisión de talento. Contacto: issues del repositorio.
